# Contributing to Punyakart

Thank you for contributing to the Punyakart platform.

Punyakart is a production donation platform developed and maintained for
Punyakart Foundation. Because the application handles donation workflows,
payment processing, donor-related information, certificates, notifications,
and administrative operations, changes should be made carefully and tested
before deployment.

## Project Ownership

The Punyakart platform is developed and maintained for Punyakart Foundation.

Technical development and maintenance are documented in `AUTHORS.md`.

The project's licensing and intellectual-property terms are defined in
`LICENSE`.

## Development Environment

### Requirements

- Node.js 20 or later
- npm
- Git
- Access to the required development environment variables

MongoDB Atlas access will be required after the database migration is
completed.
