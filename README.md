# Punyakart Foundation — Donation Portal

React + Express donation platform for **Punyakart Foundation** with Razorpay payments, 80G certificates, WhatsApp thank-you messages, email delivery, campaign management, and an admin panel.

## Technology Stack

- Frontend: React, TypeScript, Vite
- Backend: Node.js, Express, TypeScript
- Database: MongoDB Atlas
- Payments: Razorpay
- Email: SMTP
- WhatsApp: Meta WhatsApp Cloud API
- Deployment: Hostinger
- Runtime: Node.js 20+

## Requirements

- Node.js 20+
- MongoDB Atlas database
- Razorpay test or live credentials
- SMTP credentials for email delivery
- Meta WhatsApp Cloud API credentials if WhatsApp notifications are enabled
